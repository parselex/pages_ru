# Parselex RU (parselex.ru)

Внутренняя русская версия сайта Parselex — **«Parselex Право»**.
Стек: Next.js 16 (App Router) + React 19 + Tailwind 4 + shadcn/ui (zinc/amber), Prisma (задел на будущее).

> **Статус:** сайт опубликован как статическая демо-версия на GitHub Pages
> (проектный URL `https://parselex.github.io/pages_ru/`) — **без кастомного
> домена и без редиректов** (решение владельца, 2026-10-13). Весь сайт —
> `noindex` + INTERNAL-бейдж. Домен `parselex.ru` будет перенаправлен сюда
> позже, отдельным решением.
>
> **Брендинг (решение владельца, 2026-10-13):** веб-сайт Parselex —
> `parselex.ru`; единый контакт для всех доменов — `contact@parselex.ru`.

## Запуск

```bash
npm install
cp .env.example .env
npm run dev        # → http://localhost:3000
```

Сборки:

- `npm run build` — серверная сборка (`output: "standalone"`, для VPS/node-ru);
- `npm run build:static` — статический экспорт для GitHub Pages
  (`out/`, basePath `/pages_ru`, без API-роутов; чат и подписка деградируют
  в демо-режим через `NEXT_PUBLIC_STATIC_EXPORT=1`).

Деплой на Pages — автоматический: `.github/workflows/deploy-pages.yml`
(push в `main` или вручную из вкладки Actions).

## Функционал

- **Лендинг** — герой-секция, возможности, FAQ (в т.ч. FAQPage JSON-LD), футер с юр-ссылками
- **База шаблонов** (`/templates`) — собственная библиотека типовых документов: 41 шаблон
  в 11 категориях (потребительские споры, труд, ЖКХ, договоры/расписки, суд, госорганы,
  семья, банки и страховые, наследство, кредиты и долги, самозанятые/НПД) с полными
  текстами, нормативными ссылками и полями [для заполнения]; поиск, фильтр по категориям,
  копирование текста, кнопка «Заполнить с Parselex» (копирует шаблон и передаёт контекст
  в чат через sessionStorage) — всё клиентское, работает в статике (данные: `src/lib/templates.ts`)
  - Юрвычитка: ссылки/сроки/пошлины сверены по редакциям на 2026-10 (исправлены: ПП № 55→№ 2463
    для подменного фонда, подсудность мирового судьи 50 000 руб. в трудовых и заёмных исках,
    ст. 687 ГК — диспозитивный срок предупреждения; проверены 230-ФЗ, 353-ФЗ ст. 6.1-1/6.1-2,
    422-ФЗ, 214-ФЗ, ст. 333 ГК, Пленум ВС № 7 и № 50). Финальная вычитка профильным юристом —
    перед промо-запуском (см. «Осталось до продакшена»).
- **Чат-виджет** — `/api/chat` (демо)
- **Premium — 3 000 ₽/мес** (`#premium`), в подписку входят:
  - правовая база РФ; ответы со ссылками на законы и практику
  - работа с документами: разбор и создание PDF, Word, DOC
  - безлимитное общение — любое количество вопросов
  - 1М кредитов на Claude/Gemini для дел с большим объёмом; дообученные
    модели для русскоязычных пользователей; раннеры на A100/H100 для сложных задач
  - **LexZtna Secure Network** — защищённый Zero-Trust-доступ к сервисам Parselex
  - **PII Firewall** — автоматическое редактирование персональных данных до передачи в модель
- **Модалка подписки** — e-mail + два обязательных согласия (оферта рекуррентных платежей и политика ПД; условия подписки), поэтапная валидация, `POST /api/subscribe` (демо-хранилище, лимит 10 запросов/час/IP)
- **Юридические документы (черновики):** `/offer` (оферта рекуррентных платежей, 12 разделов), `/privacy` (152-ФЗ), `/terms` (условия подписки, кредиты, fair use, PDF/DOC/DOCX ≤ 20 МБ)
